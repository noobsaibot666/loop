# Store Assets Checklist

Technical requirements for iOS App Store and Google Play Store submission.

## 1. App Icons
| Platform | Requirement | Size | File Type |
| :--- | :--- | :--- | :--- |
| **All** | Master Icon | 1024 x 1024 px | PNG (no alpha) |
| **Android** | Adaptive Icon (Background) | 1024 x 1024 px | PNG |
| **Android** | Adaptive Icon (Foreground) | 1024 x 1024 px | PNG |

## 2. Screenshots (iOS)
| Device Group | Size | Orientation | Notes |
| :--- | :--- | :--- | :--- |
| **iPhone 6.7"** | 1290 x 2796 px | Portrait | iPhone 14/15 Pro Max |
| **iPhone 6.5"** | 1242 x 2688 px | Portrait | iPhone 11 Pro Max |
| **iPhone 5.5"** | 1242 x 2208 px | Portrait | iPhone 8 Plus |

## 3. Screenshots (Android)
| Device Group | Size | Orientation | Notes |
| :--- | :--- | :--- | :--- |
| **Phone** | min 1080px (short side) | Portrait | At least 4 screenshots |
| **7-inch Tablet** | 1200 x 1920 px | Portrait | Optional but recommended |
| **10-inch Tablet** | 1600 x 2560 px | Portrait | Optional but recommended |

## 4. Other Listing Assets
| Asset | Size | Platform | Notes |
| :--- | :--- | :--- | :--- |
| **Feature Graphic** | 1024 x 500 px | Google Play | Marketing banner |
| **Splash Screen** | 2048 x 2048 px | All | Centered logo |
| **Video Preview** | 1080 x 1920 px | All | Max 30 seconds |
