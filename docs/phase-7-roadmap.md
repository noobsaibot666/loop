# Phase 7 Roadmap

Date: 2026-03-12

## Purpose
Phase 7 starts after Phase 6 closes public city discovery.

The goal here is to make Alleycat runs feel deeper, sharper, and more game-like without turning the product into a heavy multiplayer build.

Status: complete

## Phase 7 focus

### 1. Task variety
Add more texture to checkpoints so runs do not all feel like the same proof loop.

Scope:
- widen checkpoint task language
- introduce clearer task categories
- improve task tone by city and district
- make generated manifests feel less repetitive

Status:
- complete
- task categories, pressure cues, and score points now ship in generated manifests

### 2. Run pressure and scoring
Make the run itself feel more meaningful after the manifest is generated.

Scope:
- tighter ghost targets
- clearer checkpoint pressure
- stronger finish summary
- better score framing than simple completion alone

Status:
- complete
- ghost framing now carries pressure labels
- finish state now exposes score, proof coverage, and clearer result framing

### 3. Challenge replay loop
Make shared challenges easier to repeat and compare.

Scope:
- cleaner rematch path
- stronger result comparison
- sharper “you beat / got beat” framing
- better challenge recap after finish

Status:
- complete
- rematch language now reacts to actual rivalry state
- challenge recap now carries stronger head-to-head framing

### 4. Result and recap surfaces
Make a finished run feel like a real event, not just a closed state.

Scope:
- stronger run recap
- cleaner checkpoint proof summary
- clearer city / district / pace story
- better bridges into Wall of Fame and rider pages

Status:
- complete
- finished runs now carry a richer recap and proof summary
- finished runs now bridge into Wall of Fame, Leaderboard, and rider pages

## Guardrails
- keep live multiplayer out
- keep comments/likes out
- keep public user-generated manifests out
- keep AI review-gated
- keep mobile-first scanning and one-hand actions

## Success condition
Phase 7 is successful if:
- Alleycat runs feel more distinct from one another
- riders get better finish payoff and replay motivation
- shared challenges feel more competitive without going live
- gameplay depth improves without bloating the product

Result:
- complete
- validated locally through build, syntax checks, and sample manifest generation across multiple live cities
